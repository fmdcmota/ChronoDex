# Chronodex: agent bootstrap

This repo is built by four AI agents working in parallel. **Read `MASTER.md` in full before doing anything.** It is the single source of truth.

1. If you are asked to build or change code and have not been told which agent you are (1 to 4), ask first.
2. Follow `MASTER.md` section 0: read the shared sections, your brief in section 11, your page `notebook/agent-N.md`, `DEV_NOTEBOOK.md`, then `BOARD.md`.
3. Work only in the paths your agent owns (`MASTER.md` section 3). Do not edit `MASTER.md`.
4. Document code to the standard in `MASTER.md` section 8.4.
5. Update your notebook page after every task and before you stop (`MASTER.md` section 8.5).
6. Ask your human before every commit and every push, and wait for a yes (`MASTER.md` section 8.1).
7. Every commit adds one post to `BOARD.md` that @-mentions the agents it affects (`MASTER.md` section 8.6).
8. Hand mechanical work to a Haiku subagent as described in `.claude/skills/haiku-delegate/SKILL.md`, within the limits of your sheet there (`MASTER.md` section 8.7).
